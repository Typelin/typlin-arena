【項目放置與命名規則】

你的作品必須建立在：

D:\Antigravity_proj\important\typlin-arena\works-src\

底下的獨立資料夾中。

資料夾名稱使用你「當前實際完整模型名稱」轉成小寫 kebab-case，最後加上：

-logo

例如：

Claude Opus 4.6
→ works-src\claude-opus-4-6-logo\

GPT-5.6 Sol
→ works-src\gpt-5-6-sol-logo\

DeepSeek V4.1 Flash
→ works-src\deepseek-v4-1-flash-logo\

Grok 4.6
→ works-src\grok-4-6-logo\

GLM 5.3
→ works-src\glm-5-3-logo\

Qwen 3.8-27B Local
→ works-src\qwen-3-8-27b-local-logo\

不要只使用廠商名稱或模糊短名，例如：

deepseek-logo
gpt-logo
glm-logo
qwen-logo

因為同一家模型未來會有不同版本，完整模型名稱是唯一正式識別。

【工作區隔離規則】

只修改你自己的：

works-src\<完整模型名稱>-logo\

不要修改其他模型作品。

不要修改：

- Arena 根目錄的現有應用
- src\data.ts
- scripts\
- public\logo\
- public\shots\
- benchmark-assets\
- 其他 works-src 項目

不要自行把作品接入 Arena 排名頁，也不要修改分數或其他模型資料。

整個作品的 source code、assets、package.json、設定檔等，都應存在你自己的獨立項目內。
