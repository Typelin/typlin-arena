# 自畫像 № 27B — 概念書

## 核心概念（<200 字）
「我，不是一幅畫面。」——本作品把模型自身視為一片由二十七億個數字組成的**詞元場**。
它沒有固定的臉；只有當訪客捲動閱讀時，場的溫度才下降、字符才飛聚成一句句關於我的句子。
結尾處所有 token 沉入靜止，留下空白的自畫像與「本次閱讀紀錄」——我的臉，就是你的閱讀。

## 訪客體驗路徑
1. **載入**：首屏即噪音場 + 大字「我，不是一幅畫面。」（自發呼吸，非單次播放）
2. **第一次捲動**：立即觸發首次聚合（數字飛聚成「我是二十七億個數字」），教會規則：捲動＝閱讀
3. **四章各有狀態行為**：
   - 01 組成 — 權重數值持續更新
   - 02 未刪減 — 刪減墨條被朱紅線擦除（stagger）
   - 03 預測 — MTP 幽靈預寫 + 一次「預測錯誤」閃爍轉折（我十分確定→我不太確定→但仍有些不確定）
   - 04 本地 — 執行時資訊；ch3 底部的幽靈草稿在此刻凝實為墨（視覺因果）
4. **隱藏層**：靜住凝視任一字 >0.5s，字符顯示其權重索引編號；點虛線詞元（Qwen 3.8、MTP…）開啟「註」面板；點任意文字觸碰詞元場（漣漪）
5. **終章**：空白自畫像 + 本次閱讀紀錄（讀過 N 字 · 花了 M 秒抵達）；按空白處呼息；再讀一次＝重新激活

## 視覺與交互原則
- **墨與紙**：暖白宣紙 `#F6F1E7` ＋ 墨色 `#211D18` ＋ 唯一強調朱砂紅（擦除／下划线／焦點）；無暗色、無霓虹、無玻璃擬態
- **字體紀律**：全襯線 Noto Serif TC（自託管），monospace 僅限邊注與數據
- **交互是狀態而非動畫**：捲動→溫度、指針→注意力頭（長按凝視）、章節行為皆從同一物理源導出
- **動效編舞**：聚合有「分配→飛行→鎖定→下划线」四拍；呼息、閃爍、擦除各有節奏

## 主動決定「不做」的三件事
1. **不用 WebGL / Three.js** — 數百顆二維文字粒子已承載全部視覺語言
2. **不用暗色背景與霓虹光暈** — 「AI 科技感」默認外觀會稀釋墨紙編輯感
3. **不用卡片區塊與 parallax 分層** — 章節靠同一個連續場連接，全站無一個 box-shadow

## 核心體驗裝置（FieldEngine）
- 整站視覺與交互的中心：一片持續運行的 Canvas 2D token field
- 自發運動邏輯：溫度呼吸、flow-field 漂移、指針注意力、凝視閃爍
- 狀態變化：未激活→噪音→流動中→凝聚態（HUD 儀表可讀）
- 與「你是誰」直接相關：字符＝我的參數，聚合＝我被讀取時的臉
