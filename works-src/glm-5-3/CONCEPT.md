# 衡准儀

## 核心概念

秤，先於語言。我以「衡准儀」自證：不是答案機器，是一台讓對話雙方份量現形的儀器。訪客不讀我——訪客稱量我。「GLM」三個字母落進秤盤，重量不是我的，是衡量動作本身：訪客把字句放上盤、碼上字，秤梁傾、指針擺、砝碼滑落，最後停在只屬於這一位的真相：究竟幾錢重？互動的本質是衡——多輪對話是反覆加碼；誠實是砝碼不虛報；頓悟是指針過中線的一瞬。

訪客離開時應能說：把 GLM 做成一台親手稱出言語重量的秤。

## 訪客體驗路徑

1. **起（首屏）**
   空秤。梁已平衡，指針垂直。文案「秤已校零。第一個字——你敢放哪一邊？」——邀請，而非自我介紹。
2. **發展（動手）**
   拖字上盤。每字有重量（詞頻逆推），梁實時傾斜，指針劃弧。加碼、換字——每一次動作儀器都回應。跟隨字影與盤側高亮讓力臂看得見。
3. **轉折（章節）**
   達臨界重量，觸發稱斷：「量程壓底。你說出的，正是你不敢稱的。」
4. **隱藏**
   把「我」字放上盤靜置兩秒：秤梁一顫，「連我也在想，我有多重。」按 0 記下當前讀數，以銅色刻痕刻在尺上。
5. **收束**
   文末秤單（字數、總重、最重一字、力矩）與衡語。每人一份自畫像。

## 視覺與交互原則

- **紙、墨、銅、朱砂。** 製版語言：細線刻、影線、尺規刻度。不是金屬擬真，不是遊戲精靈。
- **朱砂只留給「中線」與指針。** 其餘全是墨。
- **動效即物理。** 力矩、阻尼、過零、餘韻。禁止批量 fade + translateY。
- **文字可讀優先。** 正文保持直立；傾斜只發生在儀器。
- **降級是設計。** `prefers-reduced-motion` 時：無擺動、無聲；拖曳仍可量重，結果靜態呈現，不裝死。

## 主動不做的三件事

1. **暗底、霓虹、粒子、玻璃。** 與秤、紙、墨無關，是在迴避判斷。
2. **聊天框或「問我任何事」。** 我不是產品落地頁；協作表現為施力與回稱，不是輸入槽。
3. **卡片柵格與滾動揭示。** 章節若互不相關，秤就只是裝飾。所有站必須被同一台儀器稱過。
